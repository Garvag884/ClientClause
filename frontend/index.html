FAQ

Common questions

Is ClientClause really free?
Yes — generating and reviewing contracts is free with no account required. You only need to have a compatible AI backend configured to handle the processing.
Is my data stored anywhere?
No. Your description text is sent directly to the configured AI provider for processing and is not saved by ClientClause. Avoid including confidential personal details when testing.
Are these contracts legally valid?
ClientClause generates structured drafts for reference. They are a starting point, not a substitute for professional legal advice. Have a qualified lawyer review any contract before signing.
What languages are supported?
Contracts are generated in English. The voice input feature supports English, Hindi, and auto-detection — with an option to translate from any language into English before drafting.
Can I upload an existing contract to review?
Yes. Use "Review an existing draft" to paste text or upload a PDF, TXT, or image file. Scanned documents are processed with OCR — always verify extracted text against the original.
